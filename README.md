# AAM-SC NQAS Checklist

Mobile-first static web application for AAM-SC NQAS guidance.

## Included
- 12 Package Services
- 8 Areas of Concern
- 125 Measurable Elements
- 582 searchable checkpoints
- Checkpoint-wise **What to Do / What to Record / Evidence**
- Means of Verification, Assessment Method and Guiding Principle
- Responsive mobile UI
- PWA/offline cache after first successful hosted load

This version intentionally does **not** include compliance scoring, gap-entry forms, responsible-person fields, target dates or closure-evidence forms.

## GitHub Pages
The site entry point is `index.html`. Publish the repository with GitHub Pages from the `main` branch (root), or use a static host such as Cloudflare Pages.
